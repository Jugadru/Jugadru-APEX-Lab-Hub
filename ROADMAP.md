# Roadmap — APEX Lab Hub

- 1.0: independent orchestration foundation, target registry, contracts, DAG, CLI, evidence, independent hosted smoke.
- 1.1: persistent task/session registry with atomic recovery, no blind replay.
- 1.2: Foundation catalog and capability discovery integration.
- 1.3: development workflow with exact-SHA GitHub CI receipts, review/repair limits and PR preparation.
- 1.4: experiment scheduler, CPU/RSS/time limits, seed and cancellation.
- 1.5: graphics workflow via approved Asset Factory, Blender and Godot tools.
- 1.6: Engineering Lab research and experiment contracts.
- 1.7: agent gateway, actual authorized GitHub/MCP/API capabilities; no assumed access.
- 1.8: infrastructure health and executable compatibility.
- 1.9: dashboard based on real reports.
- 2.0: bounded autonomous sessions with approval gates and failure recovery.

No phase begins solely because a folder exists. Test each increment independently and preserve domain ownership.
